# Escape Artist Media — Coming Soon

A minimal, responsive static landing page for Netlify.

## Files
- `index.html` — landing page markup
- `styles.css` — layout and typography
- `assets/escape-artist-logo.svg` — supplied Escape Artist Media logo

## Typography
The Coming Soon text uses **Barlow Condensed Semibold (600)**, loaded from Google Fonts. It is available under the SIL Open Font License, so no commercial font licence is required. An internet connection is needed to load the hosted font; the page has a system sans-serif fallback.

## Deploy to Netlify
1. Upload this folder to a new GitHub repository.
2. In Netlify, choose **Add new site → Import an existing project**.
3. Connect the GitHub repository.
4. Leave the build command and publish directory blank (or set the publish directory to `.`).
5. Deploy, then add `escapeartist.media` under **Domain management** and follow Netlify's DNS instructions.

The page includes a `noindex, nofollow` directive while it is a coming-soon page.
